# Unity Spatial Puzzle Mechanics

A 3D gameplay programming prototype inspired by the mechanics of *Cubism*. This project demonstrates core gameplay engineering, spatial logic, and object interaction within a 3D environment.

### 🎮 Gameplay Engineering Focus
*   **Spatial Logic & Grid Systems:** Implemented the underlying logic for detecting shape intersections, volume filling, and 3D grid snapping.
*   **Interaction Mechanics:** Handled player input for selecting, rotating, and placing complex 3D polyominoes in real-time.
*   **Game State Management:** Developed systems to track puzzle completion conditions and manage level progression.

### 🛠️ Tech Stack
*   **Engine:** Unity 3D
*   **Language:** C#
*   **Core Concepts:** 3D Math (Quaternions, Vectors), Collision Detection, Component-Based Architecture.
